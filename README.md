# نظام حجز المشفى (نسخة تجريبية)

رابط واحد للمراجع والإدارة.
- المراجع: يضغط **تسجيل كمراجع** ويدخل اسمه ورقم هاتفه.
- الإدارة: تضغط **تعليمات** فتظهر بيانات الدخول (2001 / 2001) ثم تضغط **دخول الإدارة**.

## تجربة على حاسوبك
1. ثبّت Node.js (الإصدار 18 أو أحدث) من nodejs.org
2. افتح هذا المجلد في الطرفية ونفّذ: `node server.js`
3. افتح في المتصفح: http://localhost:3000

## النشر على الإنترنت (رابط خاص بك) — مثال: Render
1. أنشئ حساباً على github.com وارفع هذا المجلد كمستودع جديد.
2. أنشئ حساباً على render.com ← New ← Web Service ← اختر المستودع.
3. الإعدادات: Runtime = Node ، Build Command = (اتركه فارغاً) ، Start Command = `node server.js`
4. اضغط Deploy، وبعد دقائق تحصل على رابط مثل https://اسمك.onrender.com
5. (مهم) غيّر بيانات الإدارة: من Environment أضف `ADMIN_USER` و `ADMIN_PASS` بقيمك.

## ملاحظات
- الخطة المجانية في Render تنام بعد فترة خمول (أول فتح يتأخر نصف دقيقة)، والبيانات المحفوظة في ملف قد تُمسح عند إعادة النشر. هذا مقبول للتجربة فقط؛ للنسخة الحقيقية استبدل الملف بقاعدة بيانات (مثل Supabase أو PostgreSQL).
- بيانات الإدارة تظهر لكل من يضغط «تعليمات» بحسب التصميم المطلوب للنموذج التجريبي. قبل الاستخدام الفعلي احذف عرضها من الواجهة وغيّرها.
- هوية المراجع تُحفظ على جهازه فقط (بدون كلمة مرور)، وهذا كافٍ للعرض فقط.
